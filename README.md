# Livesigma Watchdog — Windows Releases

Официальные установщики Livesigma Watchdog для Windows x64. Исходный код приложения находится в закрытом репозитории и здесь не публикуется.

[Скачать последнюю версию](https://github.com/livesigma-app/livesigma-watchdog-releases/releases/latest)

## Обновления

Начиная с версии **1.0.1**, Watchdog проверяет новые стабильные релизы при запуске и каждые 6 часов. Ручная проверка: **Check for updates** в главном окне. **View update** открывает страницу официального релиза.

Если у вас версия 1.0.0, сначала установите 1.0.1 вручную. Проверка обновлений не выполняет автоматическую установку и не останавливает мониторинг. Перед установкой запланируйте перерыв, остановите мониторинг и закройте приложение.

Дополнительно можно включить уведомления GitHub: **Watch → Custom → Releases**. Доставка зависит от настроек вашей учётной записи GitHub.

## Файлы выпуска

- `LivesigmaWatchdogSetup.exe`: автономный Windows x64-установщик.
- `SHA256SUMS.txt`: контрольная сумма установщика.
- Описание изменений и выполненных проверок находится на странице каждого выпуска.

Настройки, данные лицензии, Telegram-токены и логи не распространяются. Настройки существующей установки хранятся в AppData отдельно от файлов приложения.

Установщики пока не подписаны Authenticode. Скачивайте их только из этого репозитория; Windows может предупредить о неизвестном издателе.
